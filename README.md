# Учебный проект FastAPI+SqlAlchemy
Проект, в котором создано простое одностраничное приложение и с помощью кнопок
происходит общение с базой данных и вывод результатов запросов на страницу.

## Технологии
### Проект использует:
- FastAPI
  - Получает запросы
  - Проверяет полученные в запросах данные на правильность
  - Запрашивает данные из базы данных
  - Проверяет данные ответов на правильность
  - Отправляет ответы
  - В случае ошибки выводит в консоль
- SQLAlchemy
  - Формирует запросы к базе данных
  - Получает ответ от базы данных в виде готовых объектов
- Alembic (WIP)
  - Используется для миграций
- JavaScript (без фреймворков)
  - Отправляет запросы к backend
  - Выводит полученную информацию на страницу
### Реализованный функционал
- Запрос пользователя из бд
- Создание таблиц в бд (ручной режим)
### Примечания
Все функции на backend, которые отвечают за отправку/получение запросов, 
созданы и работают полностью асинхронно.\
Все настройки для проекта осуществляются через переменные окружения. В частности:
> SECRET_KEY - секретный ключ для авторизации, пока не используется\
> DB_CONNECTION - Используемая система БД\
> DB_HOST - Адрес подключения к БД\
> DB_PORT - Порт подключения к БД\
> DB_DATABASE - Название базы данных\
> DB_USERNAME - Имя пользователя для авторизации в базе данных\
> DB_PASSWORD - Пароль для авторизации в базе данных

Строка подключения в итоге буде выглядеть так:\
"{DB_CONNECTION}://{DB_USERNAME}:{DB_PASSWORD}@{DB_HOST}:{DB_PORT}/{DB_DATABASE}"

Для запуска проекта используется команда `fastapi run`, по-умолчанию используется
порт 8000. При необходимости можно добавить при запуске параметр `--port (Порт)` 
Для запуска на другом порту. Также придётся отредактировать файл app/src/static/js
 заменив во всех запросах порт на нужный.

Для создания необходимых таблиц используется функция `init_db()` 
по пути `app.db.core`
